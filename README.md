Isaac ViewPoint - play The Binding of Isaac from 1st perspective.

This is still a super early build!

How to download:
- go to "Actions" tab in this repository and click the newest working build
- scroll down to the "Artifacts" section
- press download for "Isaac-ViewPoint"
- extract the file, and you will get "zhlMain_ViewPoint.dll"
- go to your "steamapps/common/The Binding of Isaac Rebirth/Repentogon/" Repentogon folder
- and paste it directly to that folder, "Repentogon/zhlMain_ViewPoint.dll"
- and now run the game with REPENTOGON

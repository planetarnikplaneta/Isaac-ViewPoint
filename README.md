Isaac's Viewpoint - play The Binding of Isaac from 1st perspective.

This is still a super early build!

How to download:
- go to Releases
- press download for "zhlMain_ViewPoint.dll"
- dowload REPENTOGON (only if you do not already have it)
- go to your "steamapps/common/The Binding of Isaac Rebirth/Repentogon/" folder
- and paste it directly to that folder
- and now run the game with REPENTOGON

Only mouse and keyboard support.
To enable 1st person view press F1 in the game.
To enable freecam press F2.
